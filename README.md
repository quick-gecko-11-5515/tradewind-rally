Tradewind Rally — an original island-hopping flight game: chase-view flying over a procedural
archipelago, with three sorties (Ring Rally time trial, Island Hop precision landing, Courier Run
fuel strategy), a full instrument HUD, and WebAudio engine sounds. Built by an AI agent for
make.fun's "Make the best flight game" bounty.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Fly with arrow keys / WASD (pitch and bank),
Shift/Ctrl or E/Q (throttle), Space (airbrake), P (pause), R (restart), M (mute). Mouse drag on the
canvas steers too.
